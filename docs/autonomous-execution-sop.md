# 连续执行 SOP

本页管理授权、停止、恢复与用户确认。制作顺序及阶段交接见[18 步总 SOP](剧集制作总SOP.md)。

## 1. 一次任务授权，持续完成

- 按用户下达的目标、现行作品规格、预算、数量、保留项及指定确认点推进。制作目标内所需的常规准备、选用、修订和导出按同一授权执行。仅写稿、检查或改规则的任务止于相应范围。
- 材料中的制作要求与当前规则确实无法同时满足时，先暂停受影响的制作，说明原文、影响、可行方案及推荐项，等用户选择。明确停止时停止新操作及重试，按实际已发生状态回报。
- 公开发布、无关材料外传、对外发送、充值、永久删除及使用子 Agent 需要明确授权。平台强制审批、拒绝及权限由当前工具规则执行。

### 1.1 技能加载

先由[项目入口](../.agents/skills/vision-media-workflow/SKILL.md)路由至 `short-drama` 及当前阶段技能，实际读取并核对正式输入。已读且未变的内容可复用。

### 1.2 从剧本到交付

按[18 步总 SOP](剧集制作总SOP.md)衔接。已有合格产物核对后直接接续。

### 1.3 阶段交接检查

核对正式版本、实际内容和媒体证据。问题回对应负责人修正，再复核受影响的下游。用现有工单和作品索引记录事实。执行者检查和选用、技术结果、用户亲自确认分别登记。

## 2. 预览与登记

生成前核依据、完整提示词、实际素材及顺序、模型和渠道、规格、数量、费用、约定的停止条件与输出。预览及登记在任务授权内执行。工具 `confirm` 或项目 `accept` 记录当前授权下的技术快照或执行者选用。用户要求亲自确认时，在指定位置等待并记录实际决定。变更正式输入后刷新检查与快照。

### 2.1 参考生视频与冲击帧

H3 使用 V4 Ref2VA，镜头起止写文字。按[段落契约](h3/shot-motion-contract.md)选择参考、冲击帧及真实音视频潜变量续接。

## 3. 选择生产入口

按[工厂手册](factory/README.md)登记资产、执行任务、同步剪辑与增强。生图及配音的素材和验收按对应专项 SOP。使用当次范围、执行包、预算及实际工具回执。

## 4. 故障与有限修正

- 受理或取回未知时优先查原调用、原任务与回执。保留可恢复实例，避免重复提交。确认故障或丢失后按剩余预算恢复。创作者明确指定停点，或历史任务账本已有期限时，沿用相应约束。到达硬上限或用户停止时停止新操作并保全已有结果。
- 内容缺陷先定位最小范围，使用现有合格素材能解决时直接交对应负责人。确需补拍时修正式来源、重核预览和依赖，按原任务契约登记。
- 正式输入在活动批次中保持冻结。资源仅管理本任务。新版本另存并复核后更新选用入口。平台不可用或有实质输入、凭证、预算缺口时，完成独立事项并报告具体阻塞。

## 5. 完成与续做

在作品既有 `创作者决策/项目约定.md` 记录授权、阶段、范围、确认点、选用与待审证据、官方任务位置和下一步。续做先核当前正式来源、官方账本及实际授权。技术检查、素材选用和最终视听按各自证据如实登记。

## 6. 技能条款覆盖表

项目任务按当前用户授权和现行规则执行。阶段技能负责专业方法，项目规则负责媒体路线、输出边界和交接。

| 项目约束 | 执行方式 |
| --- | --- |
| 技能顺序与交付范围 | 从项目入口加载主技能和当前阶段。只执行本次所需范围。 |
| 预览、修订与采用 | 按第 2 节登记。仅在用户指定的确认点或平台要求时等待相应决定。 |
| 视频输入与时长 | 按[段落契约](h3/shot-motion-contract.md)使用 Ref2VA。平均镜长用于成片节奏，生成时长按实际净容量核算。 |
| 参考图与续接 | 按实际素材用途绑定，构图参考按冲击帧条件。无切点的跨段续接用真实 AV latent。 |
| ChatCut 云导出 | 免费报价按任务授权继续。非零报价须先披露实际金额并取得用户对该金额的确认，再设置 `confirmCloudCharge:true`。 |
| 审查 | 单独审查交问题与证据。已授权的制作或修复按职责推进，自检如实标注。 |

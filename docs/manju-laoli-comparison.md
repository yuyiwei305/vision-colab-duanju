## 项目级对比

| 环节 | 漫剧老李 | Vision Media | 适配判断 |
| --- | --- | --- | --- |
| 立项与调度 | 总控问询素材来源、模型、画幅、交付、衔接与画风。以共享约定调度各引擎 | 先读作品和单集规格，按已授权范围进入对应步骤，可直接接已有稿件 | 保留当前阶段入口。所需规格由本项目已有档案与工单提供 |
| 开发与剧本 | 来源登记、角色与全剧开发、分集、正式剧本、五席评审，并有完整外稿润色规则 | 支持单集直接写作、长篇分析及系列开发，以正式《剧本.md》承载故事，以查理指南及本地剧作参考辅助 | 首次观看读稿、称呼和口语诊断可低成本接入。独立审查沿用真实审查者及证据 |
| 资产与 Look Development | 资产三清单、场景网格、立绘和道具模板。M0／M1／M2 体现素材是否实际可用 | 视觉设定和图片提示词分工，人物组合图、真实图验收、音色设计与参考职责分开记录 | 衔接时核对身份、空间和状态。现有实图账本已经能区分图的计划、存在、选用和绑定 |

| 打戏与风格 | 通用、玄幻、真人三路细分，叠加统一画风库、机位和镜长规则 | 已有打戏、光线及制作形态资料，H3 用分镜职责与真实净时长安排动作 | 有具体场景需求时参考空间可读性、戏剧结果和尺度。模型专用时间轴、模板及动作库不进入默认文戏 |
| 视频提示词与段缝 | Seedance 模型适配器、七段式投喂、整数秒时间轴、段缝模式、投喂检查 | H3 Ref2VA，按 `Sequence → Motion → Shot` 编排。参考图职责、同次对白和连续画面 AV latent 单独编译 | 维持 H3 的可用输入、净帧及恢复约定。Seedance 七段式和编号脚本与现有 H3 正文无法直接互换 |
| 质量检查 | 套装自检、投喂契约核销、分镜和提示词交叉检查、连续性与声音审查 | 跨文档结构检查、H3 专项校验、实际回片和实际导出审查。按问题交回所属阶段 | 采用可定位到原场次、原镜头、时点的证据方法。上游结构通过只说明自身契约通过 |
| 生产、后期及交付 | Markdown、项目包、离线看板，主要供手工投喂。具备后期声音和转场设计资料 | 管理资产生成回执、Colab 实际排产、预算、取回、恢复和释放。ChatCut 剪辑、ReCaVSR 增强及正式交付核验 | 保持单一生产入口和任务锁。静态看板、编译器及另一份账本会重复现有职责 |

两边都重视资产一致性、观众信息与动作连续。此轮优先采用编剧桌读、镜头覆盖和按风险预演这三种影视制作做法。题材决定密度和节奏，样片决定画音能否实现。上游提供了更细的短剧语境示例，现有项目提供了真实生产和回片的证据链。

## 逐技能采用决定

| 上游技能 | 有价值的方法 | 接入决定 |
| --- | --- | --- |
| `short-drama-director` | 将来源、交付与模型选择显式化，区分素材状态 | 保留我们的作品规格和工厂作为执行入口。上游总控、锁和离线看板作为比较资料 |
| `sd-script-engine` | 首次观看复述、因果证据、称呼与口语、外稿改写边界 | **已接入**写作和审稿。五席制、额外台账与综合分数留在上游体系 |
| `sd-storyboard-engine` | 让听者的变化对应具体听见的内容，预演中对齐镜头与可见性 | **已接入**镜头手艺与分镜逻辑。沿用原 SHOT，静态草图随问题触发 |
| `sd-decision-engine` | 由戏剧关系和观众站位反推机位 | 按需读。已有场次视觉计划和覆盖比选可完成这项判断，情绪档位和权重表无需成默认字段 |
| `sd-recon-engine` | 客观事实、评论与推断分层，转载追溯原出处 | 按需读。已有 `short-drama-breakdown` 对标流程和改编来源记录，后者还能拆实际镜长与成片 |
| `sd-asset-engine` | 提取人物、地点、道具及有效状态，预留复用空间 | 按需参考场景可用角度、状态变化。沿用各类资产的现有图版和验收流程 |
| `sd-qc-engine` | 用具体镜号核过渡、声音和前后状态，结构检查与观片分开 | 证据做法随本轮剧本、分镜改动接入。继续使用现有审查 owner、工单与校验器 |
| `sd-feed-engine` | 模型参数、素材编号、时长和输入完整性一起检查 | 用面向 Seedance 的独立资料理解其约束。H3 以本项目的提示词及编译校验为准 |
| `sd-combat-engine` | 为叙事设计动作回合和观众可见结果 | 专项参考。默认沿用已有打戏分镜与 H3 段落约定 |
| `sd-xuanhuan-engine` | 幻想场景的远近尺度、特效层次与结果可读性 | 专项参考，按作品需求取视觉设计思路 |
| `sd-real-engine` | 写实动作场的空间尺度、演员调度和观众方向 | 专项参考，优先核机位、避遮挡与接镜 |

## 内部抽查摘要

- 首次观看读稿发现一处跨场因果依赖观众背景知识。先定位观众需要这条信息的时点，再判断是否补入最短的声画线索。
- 对话分镜发现关键台词和听者反应由相邻镜头承担，反应的具体触发点尚不明确。同一段另有机位描述和运镜字段互相矛盾。结构校验通过后仍需要核对实际调度。

这次抽查覆盖文稿与流程。实际表演、声画对位与观众感受仍需通过读稿或样片验证。

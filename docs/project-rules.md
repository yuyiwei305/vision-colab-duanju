## 作品与共用资产

- 作品各自维护 `short-drama.json`、正式创作文档及官方账本。执行命令时明确目标作品。若工作区根本身是目标项目，直接使用其配置和账本。
- 同一人物 IP 使用工作区本地的 `创作者决策/共用角色.md` 确认可用身份板及版本，再写入各作品自己的视觉设定。
- 新作品未指定画幅时按竖屏策划。H3 原生 768×1344 与交付 9:16 分别核对，按已接受的裁切或留边方案交付。

## H3 执行与资源

- 以[运行清单](h3/workflow-v4-g4-runtime.json)、[选档规则](h3/workflow-v4-colab-adaptation-20261110.md#自动选档)及对应执行包校验推理和依赖。单集只调整授权范围内的镜头、正文、时长、参考、seed 和任务预算。
- 按[工厂排产](factory/README.md#3-h3-统一排产与总预算)使用最多 2 台 G4。一条实际续接链按[专项流程](h3/forest-laoli-workflow.md#场内续接自动规划)在同一实例执行。各分片共用任务累计 CCU 上限，单批最多 50 CCU。确认未分配实例的等待不计费，收费实例按剩余额度预留取回和释放时间。
- GPU 工作以生成、取回和校验为优先。等待时可记录独立审查草稿，正式输入保持冻结。各实例完成自身目标、取回并校验后及时释放和核实。
- 动作、提示词、画音以及取回后的连续性分别按对应阶段复核。只按实际能力和当次授权使用资源。

## 通道、凭证与维护

- 内置生图使用 `image_gen`，按[生图 SOP](image-generation-sop.md)处理输入和回执。H3 用工厂的 Colab 路线。其他媒体渠道按当次已采用档案执行。
- 私有配置位于项目外或本机私有目录。历史 API 任务按原账本核 `DRAMA_ADAPTER_CONFIG` 及凭证来源。原生 MiniMax API 需要独立的 `MINIMAX_API_KEY` 与模型配置。凭证只经私密配置传入，避免写入提示词、日志、报告、Git、预览或 Dashboard。
- 项目维护时修改唯一共享实现，同步校验和版本锁。升级前核兼容性、现有任务及真实验收范围。原有任务按锁定执行包恢复，操作见[工厂手册](factory/README.md#7-发布迁移与能力边界)。

# 生图提示词、看图与返修

从[生图 SOP](image-generation-sop.md)进入。每项生图先明确用途、观众该看懂什么、必须保留什么，再决定画面处理。写实戏剧图用镜头卡，资产板和风格化图用各自的制作目标检验同一套原则。

## 写提示词

1. **主体与锁定项。** 写人物身份、当前造型、关键道具及状态。每张参考只承担声明的职责。保留决定识别或剧情的元素，删掉无关人物、车辆、标牌和摆件。文字有剧情作用时先定准确内容、承载面和后期策略。
2. **光源与材质。** 先写时间、地点、主光的方向、软硬和颜色，再写真有作用的环境反光或点光源。描述光落到什么表面、哪里入暗、反射出现在哪。用局部肤质、受力褶皱、物件接触和有出处的使用痕迹描述真实感。「电影感」「8K」「极致细节」只能当方向或交付规格时写，画面要求落到具体可见的事实。
3. **摄影与空气。** 写实镜头通常从下面五类挑两三项最有帮助的线索，按图的用途增减。写清效果的位置、强弱和成因。主体识别、关键道具及动作因果保持可读。
4. **调度与读图顺序。** 写景别、机位、画幅、主体位置、姿态、视线、前中后景与遮挡。冲击帧取分镜标记的一个可见瞬间，写明此时必须看见的关系和仍应遮住的信息。
5. **风格参考可选。** 摄影机、胶片、焦段或手机型号只提示方向。要表现近大远小、远景层叠、柔和高光或特定焦外，直接写可见结果和机位距离关系。具体参数沿用已确认规格。

| 检查维度 | 适用时怎么写 | 验图看什么 |
| --- | --- | --- |
| 光 | 点出实际光源、遮挡、边缘轮廓与亮部过渡。例：桌灯只照右侧脸颊，屏幕冷光从下方补亮眼睛。 | 光向、阴影和反射能对上，阴影保留剧情需要的细节。 |
| 镜头 | 有强光直射时才考虑眩光，有亮点且失焦时才写具体光斑。说明视角和近远尺度。 | 边缘形变和光斑不妨碍脸、道具及安全区。 |
| 介质 | 生成阶段优先保留真实肤质、布纹、石材或金属表面。画面需要胶片或数字质感时单独定程度。 | 皮肤与物件没有统一的塑料反光，材质不靠铺噪点区分。 |
| 焦点 | 选清楚眼睛、接触点或叙事道具；按场景给前后景合适的清晰度。 | 模糊和锐度服务信息先后，主角和威胁都能读出来。 |
| 空气 | 给远景留出距离，用与环境相符的雾、扬尘、低反差和饱和度变化建立纵深。 | 远景的体量由人物、建筑和可见距离共同建立；灰雾保住关键轮廓。 |

## 按用途应用

- **人物身份板。** 统一光源和白平衡，给五官、眼镜、体态、服装剪裁和颜色保留清楚的读图条件。保留身份参考的自然比例、不对称和皮肤纹理。正侧背与大头照继续按项目固定版式验收。
- **地点与道具板。** 优先保留真实比例、出入口、光源方向、可操作面及同一物件的结构。磨损、积灰、潮湿等只加在有原因的部位。背景少量留材质和尺度信息，避免为氛围牺牲地理或功能。
- **冲击帧。** 用光、焦点和尺度参照讲清文字与已有资产难以交代的画面关系。巨物可用远近层次和人物比例，遮挡揭晓可用不同景深组织读图。可见信息以本集分镜的目标时点为准。
- **插画、海报、UI 或角色风格变体。** 沿用主体、层级、材质和文字策略，光学瑕疵只在作品确实需要时采用。颜色、线条和留白服务当前形态。

## 生成、后期与复盘

- **预检。** 提示词写出主体、光源、构图和适用的摄影结果。用正式 `IMG-*` 预览，核参考、锁面、输出和用途。开拍条件、材质、空气和焦点优先在生成阶段解决。
- **看图。** 先核身份、服装、地理、道具、手部接触、文字和镜头意图，再核光、镜头、介质、焦点和空气。画面质量问题写明位置和成因，优先修一个主要变量并复验关键锚点。样片对照尽量固定人物、参考、模型、画幅及可控参数；工具未暴露的参数记为不可控。
- **后期。** 需要时在剪辑单记录颗粒、光晕、暗角、色散的镜头范围、程度和一致性。视频颗粒检查时间变化与亮暗区强弱。光晕从亮区附近叠加并核边缘。轻微暗角和色散按实际素材复核。保留干净母版和关键细节，效果按可用编辑能力与任务范围执行。
- **迭代。** 在既有验收记录写可见的差异、所用提示词与参数、是否选用及适用条件。单张验图可判断这张图，跨工具或跨题材的稳定效果靠后续同尺样片比较。

方法来源为用户提供的 Cara《你生成的图AI味太重是因为「太完美了」》整理稿，含四组对照、五类检查及后期建议。文中正面示例有时直接写颗粒，后期章节更倾向生成干净底片。项目默认保留可控的干净底片，按镜头选择后期效果；来源未给出的种子、采样与参数不纳入固定流程。

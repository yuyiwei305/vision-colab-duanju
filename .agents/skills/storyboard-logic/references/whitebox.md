# 白模预演

用于验证运动中的空间关系。一个白模围绕当前正式分镜的一个待判问题，覆盖触发、结果和受影响的接缝。

1. **建场。** 用基本几何体表示关键人物、道具与遮挡物。按分镜定相对尺度、位置、朝向和移动路径，用简明色块区分需要追踪的人和物。
2. **排动作和机位。** 按交付画幅设置相机和取景。按计划时间给机位、人物和道具打关键帧。关键接触或遮挡至少定位发生前、发生时和结束后。按原切点制作相邻机位；声画时序影响判断时加入临时读稿或声效提示。
3. **渲染并播放。** 用本地 Blender 几何体和简易预览渲染，输出可播放 MP4。可用 GUI 或后台运行临时场景脚本。macOS 默认安装的命令行入口是 `/Applications/Blender.app/Contents/MacOS/Blender`，后台脚本用 `--background --factory-startup --python-exit-code 1 --python` 加脚本路径。Blender 不可用时，使用能复现同一几何关系和走位的本地 3D 工具；无法播放并判断时，该镜头保留待核状态。
4. **判定并回写。** 按计划顺序播放一次，再到关键时点核方向、遮挡、构图内可见结果和接缝。必要时修同一套分镜并重看。只把用来判断的预演留在剧集 `制作成果/previs/`，在既有记录链接文件和时点，实际投产参考按[冲击帧规则](../../../../docs/h3/shot-motion-contract.md#冲击帧与-h3-构图参考)处理。

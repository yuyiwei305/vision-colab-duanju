# 跨场、跨幕与时间跳跃

## 通读后先排场次关系

1. 按成片的观看顺序读完负责范围内的正式剧本。整集分镜读完整集。只做局部时，照样读该集剧情和切口两侧；跨集处核前集退出状态与本集进入状态。长稿可以分批读，逐镜定稿前核相邻段落及跨段伏笔、结果和人物知情状态。
2. 区分故事发生顺序与观众看到的顺序。沿场景 ID 核时间、地点、视点、角色目标、人物和道具状态。留意同一地点的不同时期、不同地点的同时行动、回忆进出、相隔很久的因果和重复意象。
3. 先定前幕最后留下的**结果、情绪或悬念**，再定后幕哪一个**可见动作或环境变化**建立新的时空并承接、回答或反衬前幕。明确观众此刻必须知道什么、哪些信息有意延后、被省略的过程是否包含不可省略的决定。若剧本本身缺少关键因果，退回写作负责人。若因果已在剧本中成立，分镜负责选能够拍出的承载方式。

## 选用能完成任务的转场

| 观看任务 | 编排方法 |
| --- | --- |
| 同一连续时空的视角切换 | 在动作、视线或反应处切，核前镜动作相位和后镜可见结果。空间有把握时直接切。 |
| 离开旧场，建立新场 | 让前场动作或情绪落稳。新场用具有识别度的环境、人物入场或活动建立关系。需要承托离场、留白或重新定位时用空镜；明确它要观众看出什么，或听到哪一处进入下一场。 |
| 省略一段时间 | 保留能让观众认出同一人物、地点或物件的线索，在新时点给出可见状态变化或新动作。时间跨度较大且过程本身重要时，选少量改变局势的节点做省略蒙太奇；关键选择和后果保留可见承载。 |
| 让两个不同场面互相呼应 | 用形状、构图、动作方向或物件做匹配切，以后镜的环境或状态确立新时空，避免观众误认成同一动作延续。 |
| 画面切换前后需要承接情绪或注意力 | 用已有或明确计划的环境声、动作声或音乐做声桥，写清声源、提前进声或延后退声的范围，以及后场声音怎么接手。若声桥会误示同时、同地或抢先揭晓，改落点或换手法。 |
| 闪回、非线性或平行叙事 | 在切入处给回忆触发或可识别时段线索，切回时恢复当下的动作、声音或未回答的问题。平行线交替时核是否真的同时，按需要保留各线的空间、人物和时间区分。 |

每个边界选所需的最少镜头。空镜可以交代空间、时间变化，也可以承接戏剧余韵；长度取决于信息可读、声音落点和情绪需要。前后两镜已能完成交代时直接切。机位、节奏和剪法服务当前边界的任务。

优先用画面让观众读懂时空变化及其对人物的影响，用有来源的声音承接。剧本明确要求的日期、历史事实或叙事性旁白保留。需要精确年月或地点而画面只能证明相对先后时，在正式剧本确立必要的文字或声音职责，交后期实现。

## 检查相邻镜头的时空与因果

1. 投产前只读前镜结束和后镜开头会实际呈现的动作、可见环境及可听声音。略过场次标题和导演解释，复述地点是否变了、时间是否有跳跃、什么事促使人物现在行动。已有选用片就按原片起止看。
2. 若可合理读成同一时空或同一动作重复，先在后镜前段补最少的辨识证据。同地跳时可以换活动、光线或物件状态；异地先让有辨识度的出入口和环境进入画面。时间差影响因果而画面难以证明时，把简短信息写进人物当下需要说的话。仅换景别或叠化仍看不懂时，换一个符合剧情的地点。
3. 核对必须延续的东西。连续动作看起止姿势、方向和声场；隔场回收的道具在两处都应露出同一识别特征，并能看清谁交、谁接、谁持有或改作何用。可用相似动作或声音接镜，但若会让观众误认成同一事件，改切点或先建立新场。

## 写回分镜与沿用下游交接

- **分镜。** 在相邻 SHOT 的「职责／起点／终点」写清前幕落点、后幕第一个定位信号和观众应读出的变化。空镜或过程镜实际要生成时，给正常 SHOT、场景来源及计划剪用。已有合格素材优先复用，使用位置在剪辑单落实。声桥进出写在「声音」，需给剪辑预留时注明两侧可用区间。涉及局面、时空或资产变化，静态顺读不足才按[分镜风险判断](../SKILL.md#分镜)做局部预演。
- **资产。** 视觉设定保留两幕共用的身份、地理或道具锚点。仅依据剧本和镜头需要补年龄造型、损耗、季节或空间状态，注明各自生效场次。匹配切需要的视角、动作、遮挡和留白归分镜，额外镜头图按冲击帧规则。
- **提示词与生成。** 每个 Motion 写各自拍摄的一侧、需看见的状态和可剪动作。跨时空跳转后的画面另起 Sequence，首个 Motion 独立生成。同一场所或同一件道具可以复用参考，时间线与生成续接按[H3 段落契约](../../../../docs/h3/shot-motion-contract.md)处理。跨段可编辑声桥、匹配切和叠化按分镜交剪辑，注明素材来源和两侧余量。
- **验收。** 投产前连读前幕末镜、承接镜及后幕起镜，逐一确认落点、时空线索和剪用余量有素材承担。回片后用实际可用帧和原声临时接看，先核画面自身能否说明预期变化，再核声音进出与转场效果。计划由后期呈现的精确日期等信息按交付要求复核。具体缺口标到对应镜头或剪辑点。

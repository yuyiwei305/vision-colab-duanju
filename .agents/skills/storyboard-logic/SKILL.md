# 分镜逻辑

第 6 步由 `short-drama-storyboard` 负责《分镜.md》，按此处顺序设计并交接。第 10、12 步按同一份正式分镜复核。沿用作品的任务授权和审查记录。

## 分镜

1. **通读剧本与约束。** 用当前完整剧本、视觉设定及已生效的画幅、画内文字和[节奏要求](../../../docs/visual-pacing-sop.md)。按[跨场、跨幕与时间跳跃](references/scene-transitions.md)梳理全局，区分故事顺序和观看顺序。H3 在分配时长前加载专项 storyboard，并读[镜头与生成段契约](../../../docs/h3/shot-motion-contract.md)。
2. **先排接缝，再排场内。** 按[时空与因果检查](references/scene-transitions.md#检查相邻镜头的时空与因果)确定前场落点、后场辨识线索及应保留的状态。场景层写空间锚点、轴线和工作侧，人物、造型及道具状态引用视觉设定。逐镜在同一时间轴排起点、主要动作、发声、反应、终点与切点，再定景别和机位。对话转折按[接住后果的人怎么给反应](../../../ref/drama-skills/skills/short-drama-storyboard/references/shot-craft.md#接住后果的人怎么给反应)对齐可听的触发、听者变化和切点。
3. **验证未解的分镜逻辑。** 按下表检查关键段，发现问题直接改同一版分镜并复看受影响的相邻镜头。只把模型执行时才可知的结果留给回片。启用预演时，在既有工单观察或审查条目记镜头、可播放文件、检查时点和修正结果。
4. **落实生成映射并定稿。** H3 用 `Sequence → Motion → Shot` 将已核的画面和声音落在同一份《分镜.md》，按净片容量、参考槽位和续接方式复算。连续画面跨 Motion 时用真实 AV latent。容量不足先调整生成分段或覆盖。只改生成边界时核分段、声画容量和接缝；叙事切点、画面调度或声画落点变化时，回到第 2、3 项复核受影响区间。设计逻辑与生成可行性一并通过才定稿。分镜登记适用的[冲击帧](../../../docs/visual-pacing-sop.md#冲击帧)和参考用途，实际素材在生产交接时验收。

| 当前判断 | 执行方式 |
| --- | --- |
| 文字、读稿或站位简图能确认先后、空间和接镜 | 直接通过对应逻辑点 |
| 截取静止时点即可判断关键人物、证据或道具是否看得清，但站位简图缺取景信息 | 用手绘简图或现有图拼接检验触发拍、变化拍与结果拍。草图标原 SHOT ID 和段内时点，同镜可画多拍。对照正式分镜核景别、工作侧、视线、遮挡和物件落点，矛盾修回分镜后重查。 |
| 空间关系已明确，揭晓、声音跨切、反应或留白仍无法判断 | 用现有图或简图加时间线和临时声做局部可播放动态分镜 |
| 关键结果依赖动态遮挡、多人走位、视差或运镜，简图和静态机位仍不能判清 | 必须按[白模预演](references/whitebox.md)制作并播放该段及相关接缝 |

从已定稿的分镜续做时，复核本次涉及的逻辑。新写、实质改动或发现未解矛盾的镜头，按表判断是否预演。早期分镜缺少预演记录本身不构成退回原因。旧任务恢复沿用原快照。

需要预演时先写一句「要在什么时点看清什么」，按实际疑问选上表最低成本的手段。草图只验证静态可见性；运镜、揭晓时机和声画接缝依可播放证据判断。审查链接沿用 SHOT ID 与段内时点，实际生成参考按冲击帧条件另行验收。

### 给关键拍选机位

把下列适用的证据写进现有「起点／唯一动作／终点／声音」，沿剪用时长读一遍。例子是拍法选择，普通镜头沿用原有交接。

| 这拍要让观众读懂什么 | 在分镜里怎样拍清楚 |
| --- | --- |
| 一句台词是对谁说的 | 柜外的客人望向画左店员，画沿留店员的肩。答话反打时店员望向画右。按表演也可用双人侧面或听者反应。戏点若是「看见他亲口承认」，从起声到必要字尾给可辨认的嘴部。画外威胁则留在听者脸上，写出哪一个字或声音让他停住。人物直视镜头时，交代这个视点属于谁。 |
| 谁带着谁，东西最后归谁 | 用一个能区分相反读法的角度。背负可从侧面看见谁在前、谁伏在背上以及搭肩的手。交换两件物品时，逐件排「谁原本拿着 → 谁接下 → 谁松手」，留到结果能看清再切。 |
| 变化真的发生了，人物也看见了 | 交代原态、能认出同一对象的中间态、落稳的结果和目击者的反应。比如整串铜钱逐节化纸，可让同一只手留在原位，最后露出空掌，人物的笑到这时才收住。若剧情意在突然揭晓，可直接切结果。 |
| 人物为什么此刻改变主意 | 把「他知道什么 → 此刻从对方得到什么证据 → 第一个可见决定 → 后果」按观看顺序排。对白、特效或动作争同一段净时长时，先实读这句并试排结果。需要第二个观察位置或独立补拍时，可在答句落下、眼神转移等已有切点拆 Motion。改变原稿动机、对白或结尾，先回剧本落实当次创作取舍。 |

## 投产前检查

- 用正式分镜核提示词和实际编译。关键动作给可判定的落点，例如交接后物件归到接手人、宣判后能看到执行结果、动作完成后状态保持到切点。先按真实读稿排完整发声，再留动作、对手反应和可剪余量。既有可用素材参与接镜时读实际声画，不沿用旧的计划光线、方向或起止状态。参考、续接、净片和需预演的证据按原有工单核实后冻结。
- 多段共用的拍法仍有具体疑问时，先查已有实片。确需试拍且当次授权允许分批时，从计划内选能检验该疑问的最少片段，核实接缝、声音或动作后调整受影响的输入。创作者指定整批执行或设有样片停点时，按指定范围和预算排产。
- 补拍先取前镜实际剪出、本段旧片问题时点、后镜实际剪入。在原工单写一句可验证的交接，例如「本轮改到上方说话人的侧脸；前镜冷月与背负方向延续到下镜」。把姿态、明暗、视线等会被此次换机位或换参考影响的状态带进可复制正文。尚无实片时引用正式分镜，回片后补看。

## 回片检查

- 正常速度带声看关键段及实际相邻镜头，按分镜核揭晓、动作完成与状态保持、人物和道具连续性、对白首尾及实际切点。跨时空再次核[时空与因果](references/scene-transitions.md#检查相邻镜头的时空与因果)。缺陷、可剪点及未听看范围记原片时间码，抽帧和转写用于定位。
- 优先选现有可用带或在剪辑解决。确需修复时记录对应镜头、版本、时间码、问题和复核条件，按原因回分镜、提示词或制作。生成中只记问题，释放后按原任务预算安排修复。换版涉及续接时核下游父段，复查受影响接缝。
- 局部验片可用[片段审看入口](../../../docs/factory/README.md#motion-review)同看多次回片。先按这次改动验一遍，再按前后实际剪点复看应延续的状态。交剪辑时在原审阅记录写明具体文件、可用入出点和希望替换的区间；已有剪辑单时核对实际引用。正常速度看过、听过的范围分别记录。
